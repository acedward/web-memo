Authenticated memos on Zswap offers — an experimental demo of memo-v3.

Experimental demo. Not an official Midnight product.
This page demonstrates an unratified message format built on a fork of the Midnight ledger. Never enter a seed that controls real funds. Nothing here is submitted to any network.

Read — check a memo

Give this page an offer file (a full proven transaction) and, if you have one, its memo wrapper. It will tell you what the memo says, which spend it is bound to, and exactly how much that is worth knowing. Everything happens in this browser: no network request is made while checking, and no key or wallet is involved.

About

Source, provenance and caveats: github.com/acedward/web-memo. The formats are frozen by the 00003 conformance vectors; the bech32m prefix swapmsg is provisional. A memo is not private: the pair (nullifier, memo-hash) it publishes is a correlation handle, identical memos hash identically, and a short memo can be guessed offline. Treat this as a technology demonstration, not a private messaging channel.
