Experimental demo. Not an official Midnight product.
This page demonstrates an unratified message format built on a fork of the Midnight ledger. Never enter a seed that controls real funds. No transaction is ever submitted to any chain, and the offers this page makes are anchored to a demo state created in your own browser tab — they could not settle anywhere. The only network request it ever makes is the proving payload it sends to a proof server you configure, and it says so again before the button that sends it.

Create — make a memo'd offer

Type a memo, and this page will mint a demo coin, spend it, commit the memo to that spend, have the two proofs made by a proof server you choose, and hand you the pair of artifacts. Then it checks its own work with the verifier above before showing you anything. The coin is imaginary and the offer could never settle — the proofs are real.

Read — check a memo

Pick one of the bundled demo transactions, or give this page your own offer file (a full proven transaction) and, if you have one, its memo wrapper. Either way it will tell you what the memo says, which spend it is bound to, and exactly how much that is worth knowing. Everything happens in this browser: no network request is made while checking, and no key or wallet is involved.

About

Source, provenance and caveats: github.com/acedward/web-memo. The formats are frozen by the 00003 conformance vectors; the bech32m prefix swapmsg is provisional. A memo is not private: the pair (nullifier, memo-hash) it publishes is a correlation handle, identical memos hash identically, and a short memo can be guessed offline. Treat this as a technology demonstration, not a private messaging channel.
